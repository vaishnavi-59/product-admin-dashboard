# Product Admin Dashboard

A responsive Product Admin Dashboard built with Next.js, React, TypeScript, Tailwind CSS, Axios, and the DummyJSON API.

The dashboard allows users to log in, view and manage products, search, filter, sort, paginate, view product details, and add/edit/delete products.

## Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Axios
- DummyJSON API
